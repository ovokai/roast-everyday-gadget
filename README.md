## The line

> My smart speaker answers the dog, ignores me, and once ordered 40 rolls of paper towels because a man on TV said the word "paper."

## How it runs

`main.ts` is a dependency-free Node program. It writes the single roast line to `/output/entry.txt` (falling back to a local `entry.txt` when `/output` is not writable).

```sh
node main.ts
```
